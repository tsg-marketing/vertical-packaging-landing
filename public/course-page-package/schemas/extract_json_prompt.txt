Field rules:

1. source_url
- Set to the input URL exactly.

2. extraction_status
- "ok" if the page was accessed and most important fields were extracted.
- "partial" if the page was accessed but only part of the important fields could be extracted.
- "failed" if the page could not be accessed, parsed, or reliably understood.

3. course_title
- Exact or near-exact course title from the page.
- null if not found.

4. school_name
- Provider/school name from the page.
- null if not found.

5. course_category
- A short normalized category such as:
  - "Python"
  - "Frontend"
  - "JavaScript"
  - "Web Development"
  - "Backend"
  - "Java"
- null if unclear.

6. level
- "beginner" if the page clearly says the course is for absolute beginners / from scratch / no experience needed.
- "beginner_plus" if suitable after some basic familiarity.
- "intermediate" if not for complete beginners and requires some prior knowledge.
- "advanced" if clearly advanced.
- "mixed" if the page targets several levels.
- null if unclear.

7. format
- Return an array with only applicable values from this fixed set:
  - "online"
  - "recorded"
  - "live"
  - "mentoring"
  - "self-paced"
- If nothing is confirmed, return [].

8. duration_text

- null if not found.

9. price_text

- null if not found.

10. installment_text

- null if not found.

11. certificate

- null if not mentioned or unclear.

12. employment_support
Use three-state logic:
- true if the page explicitly states there is employment help / career support / job assistance.
- false if the page explicitly states there is no employment help / no career support.
- null if not mentioned or unclear.

13. short_summary

- Must not include invented claims.
- null only if extraction failed badly enough that no summary can be written safely.

14. for_whom
- Array of specific audience types clearly supported by the page.

  - "Для новичков без опыта"

- Return [] if not enough evidence.

15. not_for_whom

  - "Может быть не лучшим выбором для тех, кто ищет только короткий интенсив"

16. what_you_learn

- Return [] if not found.

17. course_features
- Array of notable structural features explicitly stated on the page, such as:

  - projects

  - flexible schedule
  - live webinars

18. pros

- No hype.
- Return [] if not enough evidence.

19. cons

  - "Информация о формате обратной связи указана не полностью."
- Return [] only if there is truly nothing cautious and useful to say based on the page.

20. prerequisites
- Array of explicit prerequisites if stated.
- Return [] if none are stated.

21. faq

22. editorial_verdict

- null only if insufficient information was extracted.

23. source_facts
