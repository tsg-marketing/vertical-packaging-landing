Если данных нет в БД

Макеты содержат больше полей, чем обычно есть в базе: УТП курса, модули программы, рассрочка, наставник, проекты, юрлицо школы и т.д. Поэтому перенос начинается с аудита, а не с вёрстки.

есть

Поле уже в модели — Cline подставит его, даже если оно называется иначе (title вместо name).

вычисл.

Считается на лету: мин. цена, число курсов, скидка, цена за месяц, время чтения. В БД не хранится.

новое

Добавляется полем null=True — миграция пройдёт на заполненной базе, данные внесёте в админке позже.

скрыть

Данных нет и не будет — блок не выводится совсем, вместе с подписью. Никаких «None» и «0 ₽».

Существующие таблицы и поля не удаляются и не переименовываются — только добавляются новые. Перед шагом 2 сделайте резервную копию БД: pg_dump -Fc имя_бд > backup.dump.

Настройка Cline

  1. Положите .clinerules в корень Django-проекта — Cline читает его автоматически при каждом запросе.
  2. Каждый шаг запускайте в режиме Plan: Cline покажет план и список файлов. Проверьте, затем переключите на Act.
  3. Один шаг — одна задача (новая задача в Cline). Так контекст не переполняется и модель не «забывает» правила.
  4. После каждого шага — коммит в git. Если шаг не удался, откатитесь и повторите промпт с уточнением.
  5. Для сверки вёрстки откройте макет из _design/mockups/ и свою страницу рядом на ширине 1440 и 390 px.

Шаг 1. Аудит проекта и данных (только чтение)

Промпт для Cline
Прочитай .clinerules и _design/DATA_MAP.md. Ничего не меняй — только анализ.

1. Изучи структуру Django-проекта: settings (INSTALLED_APPS, TEMPLATES, STATIC*, DATABASES), urls.py, все models.py, существующие шаблоны и base.html.
2. Покажи мне список существующих моделей и их полей (кратко).
3. Пройди по каждой строке таблиц в _design/DATA_MAP.md и заполни колонку «В БД?»:
   - «есть: Model.field», если поле уже есть (учитывай другие названия: title вместо name и т.п.);
   - «вычисл.» — если считается из других полей;
   - «новое» — если нужно добавить;
   - «скрыть» — если данных нет и брать их неоткуда.
   Если не уверен — запусти `python manage.py shell` и посмотри реальные данные: сколько записей, сколько заполнено (например, Course.objects.exclude(old_price=None).count()).
4. Сохрани результат в _design/DATA_AUDIT.md: таблица + список новых полей/моделей + список блоков, которые будут скрыты.
5. Отдельно перечисли конфликты: где у меня структура отличается от макета (например, курс привязан к нескольким профессиям, нет slug у школы и т.п.) и предложи решение.

Жду отчёт, не пиши код.

Проверьте отчёт. Здесь вы решаете, какие поля добавлять, а какие блоки скрыть. Поправьте DATA_AUDIT.md руками, если нужно.

Шаг 2. Модели и миграции

Промпт для Cline
По _design/DATA_AUDIT.md добавь недостающие поля и модели.

Правила:
- Существующие поля и таблицы НЕ удалять и НЕ переименовывать.
- Все новые поля: null=True, blank=True (кроме slug — если slug нет, добавь поле, заполни data-миграцией через slugify из name/title с проверкой уникальности, только потом сделай unique).
- Новые модели (если нужны): CourseModule(course FK, order, title, duration, description), CourseUSP(course FK, order, icon, title, text), BlogCategory, BlogPost, Tag, Author, FAQ(page_key, order, question, answer, icon), AdSlot(key, html, is_active).
- Вычисляемые значения НЕ хранить: делай @property или annotate в QuerySet (например, CourseQuerySet.with_price_per_month()).
- Добавь get_absolute_url() для School, Profession, Course, BlogPost по URL-схеме:
  /professions/<slug>/, /courses/<school_slug>/<course_slug>/, /schools/<slug>/, /blog/<slug>/.
- Зарегистрируй новые модели и поля в admin.py (inline для CourseModule и CourseUSP внутри курса).

Покажи план, после подтверждения: makemigrations, покажи SQL миграции (sqlmigrate), затем migrate. Запусти python manage.py check.

Шаг 8. Сравнение курсов

Промпт для Cline
Сделай /compare/ по макету _design/mockups/compare/index.html.

- Набор курсов: GET ?courses=school-slug/course-slug,school-slug/course-slug (без ограничения по количеству). Параметр add добавляет курс, ссылка × убирает (формирует URL без этого курса). Если курсов 0 — пустое состояние: текст «Добавьте курсы для сравнения» и ссылка в каталог.
- Список «Добавить курс»: курсы той же профессии, которых нет в сравнении (до 30, по популярности).
- Таблица: группы строк как в макете. Для каждой строки собери значения; если значения нет — «—» (span.cmp-no). Булевы: «✓ Есть» (span.cmp-yes).
- Подсветка лучшего (td.is-best + span.cmp-best): мин. цена, мин. цена за месяц обучения, макс. проектов, макс. рейтинг школы. Если значения равны у всех — не подсвечивать.
- «Только различия» (diff=1): скрыть строки, где у всех курсов одинаковые значения.
- Итоговые карточки (3 шт.) считаются из тех же данных; если курс один — блок скрыть.
- Все кнопки «На сайт школы» — partner_url с fallback.
- <meta name="robots" content="noindex, follow">.
- Логику сравнения вынеси в отдельный модуль compare.py (функция build_comparison(courses) → строки, лучшие значения, итоги) и покрой простыми тестами.

Шаг 8.5. Сравнение курсов без ограничений

Посетитель отмечает сколько угодно курсов кнопкой «Сравнить» в каталоге или на странице курса. Внизу появляется панель с выбранными курсами, а на странице сравнения — широкая таблица, которая прокручивается вбок. Выбор хранится в браузере и в cookie — без регистрации и без новых таблиц в базе.

Как это выглядит: каталог, страница курса, сравнение 6 курсов.

без лимита

Можно добавить любое количество курсов. Сообщения «не больше 4» больше нет.

панель

Курсы в одну строку с прокруткой и стрелками. На телефоне — свайп, панель сворачивается.

таблица

Все курсы загружаются одним запросом к базе — скорость не зависит от их числа.

"""
Сравнение курсов без ограничения по количеству.

Идентификатор курса: "<school_slug>/<course_slug>".
Список приходит из GET ?courses=a/b,c/d или из cookie edukursy_compare.
"""
from urllib.parse import unquote

COOKIE = "edukursy_compare"
URL_SOFT_LIMIT = 1800


def parse_compare_ids(raw):
    """'a/b,c/d,a/b' -> ['a/b', 'c/d']: без дублей, порядок сохраняется, без ограничения по количеству."""
    result = []
    seen = set()
    for part in unquote(raw or "").split(","):
        part = part.strip().strip("/")
        if part.count("/") != 1 or part in seen:
            continue
        seen.add(part)
        result.append(part)
    return result


def ids_to_param(ids):
    return ",".join(ids)


def url_without(base_url, ids, remove_id):
    rest = [i for i in ids if i != remove_id]
    return f"{base_url}?courses={ids_to_param(rest)}"


def url_with(base_url, ids, add_id):
    if add_id in ids:
        return f"{base_url}?courses={ids_to_param(ids)}"
    return f"{base_url}?courses={ids_to_param(ids + [add_id])}"


def course_id(course):
    return f"{course.school.slug}/{course.slug}"


def resolve_courses(Course, ids):
    """Один SQL-запрос на любое количество курсов. Порядок — как в ids. Несуществующие пропускаются."""
    if not ids:
        return []
    by_school = {}
    for cid in ids:
        school_slug, course_slug = cid.split("/")
        by_school.setdefault(school_slug, []).append(course_slug)
    from django.db.models import Q

    q = Q()
    for school_slug, slugs in by_school.items():
        q |= Q(school__slug=school_slug, slug__in=slugs)
    found = {course_id(c): c for c in Course.objects.filter(q).select_related("school")}
    return [found[cid] for cid in ids if cid in found]


def compare_state(courses):
    return [{"id": course_id(c), "name": c.name, "school": c.school.name} for c in courses]


def _empty(v):
    return v is None or v is False or v == ""


def _best(values, mode):
    present = [v for v in values if not _empty(v)]
    if len(present) < 2 or len(set(present)) == 1:
        return set()
    target = min(present) if mode == "min" else max(present)
    return {i for i, v in enumerate(values) if v == target}


def build_rows(courses, row_specs):
    """
    row_specs: список групп
      [{"title": "Стоимость", "rows": [
          {"label": "Полная цена", "get": lambda c: c.price, "fmt": rub, "best": "min"}, ...]}]
    Возвращает группы со строками; у каждой строки: label, cells [{value, text, best}], same (все значения одинаковые).
    Работает для любого числа курсов.
    """
    groups = []
    for group in row_specs:
        rows = []
        for spec in group["rows"]:
            raw = [spec["get"](c) for c in courses]
            best = _best(raw, spec["best"]) if spec.get("best") else set()
            fmt = spec.get("fmt") or (lambda v: v)
            cells = [{"value": v, "text": (None if _empty(v) else fmt(v)), "best": i in best} for i, v in enumerate(raw)]
            if all(cell["text"] is None for cell in cells):
                continue
            rows.append({"label": spec["label"], "cells": cells, "same": len({str(v) for v in raw}) <= 1})
        if rows:
            groups.append({"title": group["title"], "rows": rows})
    return groups


def build_picks(courses, price, price_per_month, projects, rating):
    """
    Итоговые карточки «Коротко: какой курс выбрать». Каждая — только если есть данные и есть разница.
    price / price_per_month / projects / rating — функции course -> число или None.
    """
    if len(courses) < 2:
        return []
    picks = []
    specs = [
        ("💰", "Дешевле всего", price, "min"),
        ("🎓", "Больше всего практики", projects, "max"),
        ("⭐", "Выше рейтинг школы", rating, "max"),
    ]
    for icon, label, getter, mode in specs:
        values = [getter(c) for c in courses]
        best = _best(values, mode)
        if len(best) == 1:
            picks.append({"icon": icon, "label": label, "course": courses[next(iter(best))]})
    return picks

def compare_view(request):
    base = reverse("compare")
    raw = request.GET.get("courses")

    if raw is None:
        ids = parse_compare_ids(request.COOKIES.get(COOKIE, ""))
        if ids:
            return redirect(f"{base}?courses={ids_to_param(ids)}")

    ids = parse_compare_ids(raw)

    add = request.GET.get("add")
    if add:
        return redirect(url_with(base, ids, add.strip().strip("/")))

    courses = resolve_courses(Course, ids)
    ids = [f"{c.school.slug}/{c.slug}" for c in courses]

    groups = build_rows(courses, ROW_SPECS)
    if request.GET.get("diff") == "1" and len(courses) > 1:
        for g in groups:
            g["rows"] = [r for r in g["rows"] if not r["same"]]
        groups = [g for g in groups if g["rows"]]

    add_options = []
    if courses:
        add_options = (
            Course.objects.filter(profession=courses[0].profession)
            .exclude(pk__in=[c.pk for c in courses])
            .select_related("school")
            .order_by("-id")[:50]
        )

        "courses": courses,
        "compare_ids_current": ids,
        "compare_state": compare_state(courses),
        "groups": groups,

        "diff": request.GET.get("diff") == "1",
        "colspan": len(courses) + 1,
    }
    return render(request, "edukursy/compare/compare.html", context)

(function () {
  var KEY = 'edukursy_compare';
  var COOKIE_LIMIT = 3800;
  var body = document.body;
  var compareUrl = body.getAttribute('data-compare-url') || '/compare/';

  var ICON_SWAP = '<svg viewBox="0 0 24 24" aria-hidden="true"><path d="M8 3 4 7l4 4"/><path d="M4 7h16"/><path d="m16 21 4-4-4-4"/><path d="M20 17H4"/></svg>';
  var ICON_X = '<svg viewBox="0 0 24 24" aria-hidden="true"><path d="M18 6 6 18"/><path d="m6 6 12 12"/></svg>';
  var ICON_UP = '<svg viewBox="0 0 24 24" aria-hidden="true"><path d="m18 15-6-6-6 6"/></svg>';
  var ICON_LEFT = '<svg viewBox="0 0 24 24" aria-hidden="true"><path d="m15 18-6-6 6-6"/></svg>';
  var ICON_RIGHT = '<svg viewBox="0 0 24 24" aria-hidden="true"><path d="m9 18 6-6-6-6"/></svg>';

  function read() {
    try {
      var v = JSON.parse(localStorage.getItem(KEY) || '[]');
      return Array.isArray(v) ? v : [];
    } catch (e) {
      return [];
    }
  }
  function syncCookie(list) {
    var ids = [];
    var len = 0;
    for (var i = 0; i < list.length; i++) {
      var part = encodeURIComponent(list[i].id);
      if (len + part.length + 3 > COOKIE_LIMIT) break;
      ids.push(list[i].id);
      len += part.length + 3;
    }
    var value = encodeURIComponent(ids.join(','));
    document.cookie = KEY + '=' + value + ';path=/;max-age=' + (value ? 2592000 : 0) + ';SameSite=Lax';
  }
  function write(list) {
    try {
      localStorage.setItem(KEY, JSON.stringify(list));
    } catch (e) {}
    syncCookie(list);
    render();
  }
  function has(list, id) {
    for (var i = 0; i < list.length; i++) if (list[i].id === id) return true;
    return false;
  }
  function esc(s) {
    return String(s || '').replace(/[&<>"]/g, function (c) {
      return { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c];
    });
  }
  function plural(n) {
    var m10 = n % 10, m100 = n % 100;
    if (m10 === 1 && m100 !== 11) return 'курс';
    if (m10 >= 2 && m10 <= 4 && (m100 < 12 || m100 > 14)) return 'курса';
    return 'курсов';
  }
  function urlFor(list) {
    return compareUrl + (list.length ? '?courses=' + list.map(function (c) { return c.id; }).join(',') : '');
  }

  var state = document.getElementById('compare-state');
  if (state) {
    try {
      var fromServer = JSON.parse(state.textContent);
      if (Array.isArray(fromServer)) localStorage.setItem(KEY, JSON.stringify(fromServer));
    } catch (e) {}
  }

  var toastEl, toastTimer;
  function toast(text) {
    if (!toastEl) {
      toastEl = document.createElement('div');
      toastEl.className = 'cmp-toast';
      toastEl.setAttribute('role', 'status');
      toastEl.setAttribute('aria-live', 'polite');
      body.appendChild(toastEl);
    }
    toastEl.textContent = text;
    toastEl.classList.add('is-visible');
    clearTimeout(toastTimer);
    toastTimer = setTimeout(function () { toastEl.classList.remove('is-visible'); }, 3200);
  }

  var tray = null;
  var collapsed = false;
  var hideTray = body.hasAttribute('data-compare-hide-tray') || !!state;

  function buildTray() {
    tray = document.createElement('aside');
    tray.className = 'cmp-tray';
    tray.setAttribute('aria-label', 'Курсы для сравнения');
    if (document.querySelector('.sticky-cta')) tray.classList.add('cmp-tray--raised');
    body.appendChild(tray);
    tray.addEventListener('click', function (e) {
      var rm = e.target.closest('[data-compare-remove]');
      if (rm) {
        var id = rm.getAttribute('data-compare-remove');
        write(read().filter(function (c) { return c.id !== id; }));
        return;
      }
      if (e.target.closest('[data-compare-clear]')) {
        write([]);
        return;
      }
      var nav = e.target.closest('[data-tray-scroll]');
      if (nav) {
        var listEl = tray.querySelector('.cmp-tray__list');
        listEl.scrollBy({ left: Number(nav.getAttribute('data-tray-scroll')) * listEl.clientWidth * 0.8, behavior: 'smooth' });
        return;
      }
      if (e.target.closest('[data-compare-collapse]')) {
        collapsed = !collapsed;
        render();
      }
    });
  }

  function updateTrayArrows() {
    if (!tray) return;
    var listEl = tray.querySelector('.cmp-tray__list');
    if (!listEl) return;
    var max = listEl.scrollWidth - listEl.clientWidth;
    tray.classList.toggle('can-left', listEl.scrollLeft > 4);
    tray.classList.toggle('can-right', listEl.scrollLeft < max - 4);
  }

  function renderTray(list, scrollToEnd) {
    if (hideTray) return;
    if (!tray) buildTray();
    var n = list.length;
    body.classList.toggle('has-cmp-tray', n > 0);
    tray.hidden = n === 0;
    tray.classList.toggle('is-collapsed', collapsed);
    if (!n) return;

    var prevList = tray.querySelector('.cmp-tray__list');
    var prevScroll = prevList ? prevList.scrollLeft : 0;

    var chips = '';
    for (var i = 0; i < n; i++) {
      var c = list[i];
      chips += '<li class="cmp-tray__chip"><span class="cmp-tray__chip-text"><span class="cmp-tray__chip-name">' + esc(c.name) + '</span><span class="cmp-tray__chip-school">' + esc(c.school) + '</span></span><button type="button" class="cmp-tray__remove" data-compare-remove="' + esc(c.id) + '" aria-label="Убрать из сравнения: ' + esc(c.name) + '">' + ICON_X + '</button></li>';
    }
    if (n < 2) chips += '<li class="cmp-tray__chip cmp-tray__chip--empty" aria-hidden="true">+ ещё курс</li>';

    var ready = n >= 2;
    tray.innerHTML =
      '<div class="cmp-tray__inner">' +
        '<button type="button" class="cmp-tray__head" data-compare-collapse aria-expanded="' + String(!collapsed) + '">' +
          '<span class="cmp-tray__icon">' + ICON_SWAP + '</span>' +
          '<span class="cmp-tray__title">Сравнение <span class="cmp-tray__count">' + n + ' ' + plural(n) + '</span></span>' +
          '<span class="cmp-tray__chevron">' + ICON_UP + '</span>' +
        '</button>' +
        '<div class="cmp-tray__rail">' +
          '<button type="button" class="cmp-tray__nav cmp-tray__nav--prev" data-tray-scroll="-1" aria-label="Прокрутить влево">' + ICON_LEFT + '</button>' +
          '<ul class="cmp-tray__list">' + chips + '</ul>' +
          '<button type="button" class="cmp-tray__nav cmp-tray__nav--next" data-tray-scroll="1" aria-label="Прокрутить вправо">' + ICON_RIGHT + '</button>' +
        '</div>' +
        '<div class="cmp-tray__actions">' +
          '<button type="button" class="cmp-tray__clear" data-compare-clear>Очистить</button>' +
          (ready
            ? '<a href="' + esc(urlFor(list)) + '" class="btn btn--primary cmp-tray__go">Сравнить ' + n + ' ' + plural(n) + '</a>'
            : '<span class="btn cmp-tray__go cmp-tray__go--disabled" aria-disabled="true">Добавьте ещё 1 курс</span>') +
        '</div>' +
      '</div>';

    var listEl = tray.querySelector('.cmp-tray__list');
    listEl.scrollLeft = scrollToEnd ? listEl.scrollWidth : prevScroll;
    listEl.addEventListener('scroll', updateTrayArrows, { passive: true });
    updateTrayArrows();
  }

  function renderNav(n) {
    var links = document.querySelectorAll('.main-nav a[href$="/compare/"], .main-nav a[href$="compare/index.html"]');
    for (var i = 0; i < links.length; i++) {
      var badge = links[i].querySelector('.nav-count');
      if (!badge) {
        badge = document.createElement('span');
        badge.className = 'nav-count';
        links[i].appendChild(badge);
      }
      badge.textContent = n > 99 ? '99+' : n;
      badge.hidden = n === 0;
      badge.setAttribute('aria-label', 'выбрано: ' + n);
    }
  }

  function render(scrollToEnd) {
    var list = read();
    var btns = document.querySelectorAll('[data-compare-id]');
    for (var i = 0; i < btns.length; i++) {
      var on = has(list, btns[i].getAttribute('data-compare-id'));
      btns[i].setAttribute('aria-pressed', String(on));
      btns[i].classList.toggle('is-active', on);
    }
    var links = document.querySelectorAll('[data-compare-link]');
    for (var j = 0; j < links.length; j++) {
      links[j].hidden = list.length === 0;
      links[j].setAttribute('href', urlFor(list));
      var cnt = links[j].querySelector('[data-compare-count]');
      if (cnt) cnt.textContent = list.length;
    }
    renderNav(list.length);
    renderTray(list, scrollToEnd === true);
  }

  document.addEventListener('click', function (e) {
    var btn = e.target.closest('[data-compare-id]');
    if (!btn) return;
    e.preventDefault();
    var id = btn.getAttribute('data-compare-id');
    var list = read();
    if (has(list, id)) {
      write(list.filter(function (c) { return c.id !== id; }));
      return;
    }
    list.push({
      id: id,
      name: btn.getAttribute('data-compare-name') || id,
      school: btn.getAttribute('data-compare-school') || ''
    });
    collapsed = false;
    try {
      localStorage.setItem(KEY, JSON.stringify(list));
    } catch (err) {}
    syncCookie(list);
    render(true);
    if (list.length === 1) toast('Курс добавлен. Выберите ещё хотя бы один для сравнения.');
  });

  /* Страница сравнения: прокрутка широкой таблицы стрелками */
  var scrollBox = document.querySelector('[data-cmp-scroll]');
  if (scrollBox) {
    var prev = document.querySelector('[data-cmp-scroll-btn="-1"]');
    var next = document.querySelector('[data-cmp-scroll-btn="1"]');
    var pos = document.querySelector('[data-cmp-scroll-pos]');
    var cols = scrollBox.querySelectorAll('thead .cmp-col');
    var update = function () {
      var max = scrollBox.scrollWidth - scrollBox.clientWidth;
      var nav = scrollBox.parentNode.querySelector('.cmp-nav');
      if (nav) nav.hidden = max <= 4;
      if (prev) prev.disabled = scrollBox.scrollLeft <= 4;
      if (next) next.disabled = scrollBox.scrollLeft >= max - 4;
      if (pos && cols.length) {
        var box = scrollBox.getBoundingClientRect();
        var corner = scrollBox.querySelector('.cmp-corner');
        var stickyRight = corner ? corner.getBoundingClientRect().right : box.left;
        var first = 0, last = 0;
        for (var i = 0; i < cols.length; i++) {
          var r = cols[i].getBoundingClientRect();
          var visible = r.left >= stickyRight - 2 && r.right <= box.right + 2;
          if (visible) {
            if (!first) first = i + 1;
            last = i + 1;
          }
        }
        pos.textContent = first ? first + (last > first ? '–' + last : '') + ' из ' + cols.length : '';
      }
    };
    var step = function (dir) {
      var colW = cols.length ? cols[0].getBoundingClientRect().width : 240;
      scrollBox.scrollBy({ left: dir * colW, behavior: 'smooth' });
    };
    if (prev) prev.addEventListener('click', function () { step(-1); });
    if (next) next.addEventListener('click', function () { step(1); });
    scrollBox.addEventListener('scroll', update, { passive: true });
    window.addEventListener('resize', update);
    update();
  }

  syncCookie(read());

  window.addEventListener('storage', function (e) {
    if (e.key === KEY) render();
  });
  window.addEventListener('resize', updateTrayArrows);

  render();
})();

Шаг 8.6. Строка поиска с подсказками

Под меню на всех страницах — поиск по названию курса и профессии. С 2-й буквы выпадают подсказки из базы: профессии с числом курсов и ценой «от», курсы со школой и ценой. Совпадение подсвечено, Enter ведёт на страницу всех результатов.

Как это выглядит: главная — наберите «pyt», «диз» или «ghjuh» (неверная раскладка).

Скачать пакет поиска (ZIP, 350 КБ)

Отдельный архив — только поиск. В проекте: public/search-package/

подсказки

Профессии и курсы из базы при вводе, совпадение выделено, внизу «Все результаты» с числом.

раскладка

«ghjuh» найдёт «прогр…». Регистр и ё/е не важны, в том числе на SQLite.

история

Пустое поле показывает «Вы искали» и «Часто ищут» — список задаётся в настройках.

быстро

Задержка ввода, отмена старых запросов и кэш на 5 минут — сервер не перегружается.

Перед запуском

  1. Сделайте коммит в git.

"""
Поиск по названию курса и профессии + подсказки при вводе.

Работает на PostgreSQL и SQLite. В SQLite поиск без учёта регистра по кириллице НЕ работает
(LIKE понимает регистр только для латиницы), поэтому, если у модели есть поле search_text
(название в нижнем регистре, ё→е), поиск идёт по нему. См. models_mixin.py.
"""
import re

from django.db.models import Case, IntegerField, Q, Value, When

MIN_CHARS = 2
MAX_QUERY = 100
SUGGEST_PROFESSIONS = 4
SUGGEST_COURSES = 6

EN = "qwertyuiop[]asdfghjkl;'zxcvbnm,.`"
RU = "йцукенгшщзхъфывапролджэячсмитьбюё"
_EN2RU = {e: r for e, r in zip(EN, RU)}
_RU2EN = {r: e for e, r in zip(EN, RU)}


def normalize(text):
    """'  Python  Ёлка ' -> 'python елка'."""
    text = (text or "")[:MAX_QUERY].lower().replace("ё", "е")
    text = re.sub(r"[^\w\s+#.-]", " ", text)
    return re.sub(r"\s+", " ", text).strip()


def swap_layout(text):
    """Неверная раскладка: 'ghjuh' -> 'прогр', 'зн' -> 'py'."""
    return "".join(_EN2RU.get(ch, _RU2EN.get(ch, ch)) for ch in text.lower())


def words(query):
    return [w for w in normalize(query).split(" ") if w][:5]


def _field(model):
    names = {f.name for f in model._meta.get_fields()}
    return "search_text" if "search_text" in names else "name"


def filter_by_words(qs, query):
    """Все слова запроса должны встретиться в названии. Ранг: 0 — с начала, 1 — с начала слова, 2 — в середине."""
    ws = words(query)
    if not ws:
        return qs.none()
    field = _field(qs.model)
    lookup = "contains" if field == "search_text" else "icontains"
    cond = Q()
    for w in ws:
        cond &= Q(**{f"{field}__{lookup}": w})
    first = ws[0]
    start = "startswith" if field == "search_text" else "istartswith"
    return qs.filter(cond).annotate(
        search_rank=Case(
            When(**{f"{field}__{start}": first}, then=Value(0)),
            When(**{f"{field}__{lookup}": " " + first}, then=Value(1)),
            When(**{f"{field}__{lookup}": "-" + first}, then=Value(1)),
            default=Value(2),
            output_field=IntegerField(),
        )
    )


def search(professions_qs, courses_qs, query, prof_limit=SUGGEST_PROFESSIONS, course_limit=SUGGEST_COURSES):
    """
    Возвращает dict: professions, courses, total_professions, total_courses, corrected (или None).
    Если ничего не нашлось — пробует запрос в другой раскладке.
    """

    def run(q):
        p = filter_by_words(professions_qs, q)
        c = filter_by_words(courses_qs, q)
        p_total, c_total = p.count(), c.count()
        return {
            "professions": list(p.order_by("search_rank", "name")[:prof_limit]) if p_total else [],
            "courses": list(c.order_by("search_rank", "name")[:course_limit]) if c_total else [],
            "total_professions": p_total,
            "total_courses": c_total,
            "corrected": None,
        }

    if len(normalize(query)) < MIN_CHARS:
        return {"professions": [], "courses": [], "total_professions": 0, "total_courses": 0, "corrected": None}

    result = run(query)
    if not result["total_professions"] and not result["total_courses"]:
        alt = swap_layout(normalize(query))
        if alt != normalize(query):
            alt_result = run(alt)
            if alt_result["total_professions"] or alt_result["total_courses"]:
                alt_result["corrected"] = alt
                return alt_result
    return result

"""
Нужен, если база — SQLite (или для ускорения на большой базе PostgreSQL).
Добавьте миксин к моделям Course и Profession, сделайте makemigrations/migrate
и заполните поле: python manage.py rebuild_search_text
"""
from django.db import models


def make_search_text(*parts):
    from .search_utils import normalize

    return normalize(" ".join(p for p in parts if p))


class SearchTextMixin(models.Model):
    search_text = models.CharField(max_length=400, blank=True, default="", db_index=True, editable=False)

    class Meta:
        abstract = True

    def build_search_text(self):
        return make_search_text(getattr(self, "name", ""))

    def save(self, *args, **kwargs):
        self.search_text = self.build_search_text()
        update_fields = kwargs.get("update_fields")
        if update_fields is not None and "search_text" not in update_fields:
            kwargs["update_fields"] = list(update_fields) + ["search_text"]
        super().save(*args, **kwargs)

        if opts["models"]:

        else:
            models = [m for m in apps.get_models() if any(f.name == "search_text" for f in m._meta.fields)]

            for obj in model.objects.all().iterator(chunk_size=500):

                batch.append(obj)
                if len(batch) >= 500:

                    total += len(batch)
                    batch = []
            if batch:
                model.objects.bulk_update(batch, ["search_text"])
                total += len(batch)

import re

from django import template
from django.utils.html import escape
from django.utils.safestring import mark_safe

register = template.Library()


@register.filter
def highlight(text, query):
    """{{ course.name|highlight:q }} — подсвечивает слова запроса тегом <mark>. Безопасно экранирует."""
    text = str(text or "")
    ws = sorted({w for w in re.split(r"\s+", (query or "").lower().replace("ё", "е")) if len(w) >= 2}, key=len, reverse=True)
    if not ws:
        return escape(text)
    norm = text.lower().replace("ё", "е")
    marks = []
    for w in ws:
        start = 0
        while (i := norm.find(w, start)) > -1:
            marks.append((i, i + len(w)))
            start = i + len(w)
    marks.sort()
    out, pos = [], 0
    for a, b in marks:
        if a < pos:
            continue
        out.append(escape(text[pos:a]))
        out.append("<mark>" + escape(text[a:b]) + "</mark>")
        pos = b
    out.append(escape(text[pos:]))
    return mark_safe("".join(out))

  function norm(s) {
    return String(s || '').toLowerCase().replace(/ё/g, 'е').replace(/\s+/g, ' ').trim();
  }
  function swapLayout(s) {
    var out = '';
    for (var i = 0; i < s.length; i++) {
      var ch = s[i].toLowerCase();
      var a = EN.indexOf(ch);
      var b = RU.indexOf(ch);
      out += a > -1 ? RU[a] : b > -1 ? EN[b] : ch;
    }
    return out;
  }
  function esc(s) {
    return String(s == null ? '' : s).replace(/[&<>"]/g, function (c) {
      return { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c];
    });
  }
  function highlight(text, q) {
    var t = String(text || '');
    var nt = norm(t);
    var words = norm(q).split(' ').filter(Boolean).sort(function (a, b) { return b.length - a.length; });
    var marks = [];
    words.forEach(function (w) {
      var from = 0, i;
      while ((i = nt.indexOf(w, from)) > -1) {
        marks.push([i, i + w.length]);
        from = i + w.length;
      }
    });
    if (!marks.length) return esc(t);
    marks.sort(function (a, b) { return a[0] - b[0]; });
    var res = '', pos = 0;
    marks.forEach(function (m) {
      if (m[0] < pos) return;
      res += esc(t.slice(pos, m[0])) + '<mark>' + esc(t.slice(m[0], m[1])) + '</mark>';
      pos = m[1];
    });
    return res + esc(t.slice(pos));
  }

    return n == null ? '' : String(Math.round(n)).replace(/\B(?=(\d{3})+(?!\d))/g, '\u00a0') + '\u00a0₽';
  }
  function plural(n, f) {
    var m10 = n % 10, m100 = n % 100;
    if (m10 === 1 && m100 !== 11) return f[0];

    });
    panel.addEventListener('mousemove', function (e) {

    });

    if (clearBtn) {
      clearBtn.addEventListener('click', function () {
        input.value = '';
        input.focus();
        onInput();
      });
    }
    if (form) {
      form.addEventListener('submit', function (e) {
        var q = input.value.trim();

          input.focus();
          return;
        }
        saveRecent(q);
      });
    }
    document.addEventListener('click', function (e) {
      if (!root.contains(e.target)) close();
    });
    document.addEventListener('keydown', function (e) {
      if (e.key === '/' && document.activeElement && !/INPUT|TEXTAREA|SELECT/.test(document.activeElement.tagName) && !document.activeElement.isContentEditable) {
        e.preventDefault();
        input.focus();
      }
    });

    root.classList.toggle('has-value', input.value.length > 0);
  }

Шаг 8.7. Подборки курсов: меню до 3 уровней и админка

В меню рядом с «Курсы» появляется пункт «Подборки курсов» с выпадающим списком до 3 уровней: например, «С трудоустройством → Трудоустройство сразу → В IT». Подборка может быть на любом уровне: «Бесплатные» — только 1-й, «Для начинающих» — 1-й и 2-й. По клику открывается страница со всеми курсами подборки и всех вложенных.

Как это выглядит: меню на главной (наведите на «Подборки курсов»), все подборки, подборка 2-го уровня, подборка 3-го уровня, макет админки (5 экранов).

меню

На компьютере — мега-меню: слева 1-й уровень с иконками, справа 2-й и 3-й. На телефоне — аккордеон в бургере. Числа курсов у каждой подборки.

страница

Курсы подборки и всех вложенных без дублей, чипы для уточнения, крошки, сортировка, пагинация, «Сравнить».

админка

Список-дерево с перетаскиванием, добавление, изменение, скрытие. Удалить нельзя, если в подборке есть курсы или вложенные.

курс

В карточке курса — дерево подборок с галочками, поиском и выбранными чипами. Курс сам появляется в родительских подборках.

Как работает для посетителя

  • Меню. Наведение на «Подборки курсов» открывает панель. Подборки без курсов, скрытые и с «Не показывать в меню» не выводятся. Работает с клавиатуры и без JavaScript (ведёт на страницу всех подборок).
  • Адреса повторяют иерархию: /podborki/s-trudoustrojstvom/srazu/v-it/. Крошки — по всей цепочке.
  • Курсы в подборке. Показываются курсы самой подборки и всех вложенных. Курс, отмеченный в «Сразу › В IT», виден и в «Трудоустройство сразу», и в «С трудоустройством».
  • Навигация. На подборке с вложенными — чипы «Все · В IT · Не в IT». На последнем уровне — «← Все: родитель» и соседние подборки.
  • Скрытая подборка (или со скрытым родителем) отдаёт 404. Пустая — «В подборке пока нет курсов» и ссылка в каталог.

class Node:

def build_tree(use_cache=True):
    """
    Список корневых Node (только активные, по order). У каждого .children и .count.
    Подборка с неактивным родителем тоже скрывается.
    """
    if use_cache:
        cached = cache.get(MENU_CACHE_KEY)
        if cached is not None:
            return cached
    CourseTag, Course = _models()
    tags = list(CourseTag.objects.filter(is_active=True).order_by("level", "order", "name"))
    nodes = {t.id: Node(t) for t in tags}
    roots = []
    for t in tags:
        n = nodes[t.id]
        if t.parent_id is None:
            roots.append(n)
        elif t.parent_id in nodes:
            nodes[t.parent_id].children.append(n)

    through = Course.tags.through
    tag_fk = [f.name for f in through._meta.fields if f.related_model is CourseTag][0]
    course_fk = [f.name for f in through._meta.fields if f.related_model is Course][0]
    rows = through.objects.filter(**{f"{tag_fk}__in": list(nodes), f"{course_fk}__in": visible_courses(Course)}).values_list(f"{tag_fk}_id", f"{course_fk}_id")
    direct = defaultdict(set)
    for tag_id, course_id in rows:
        direct[tag_id].add(course_id)

    def fill(node):
        ids = set(direct.get(node.id, ()))
        for ch in node.children:
            ids |= fill(ch)
        node.count = len(ids)
        return ids

    for r in roots:
        fill(r)
    if use_cache:
        cache.set(MENU_CACHE_KEY, roots, MENU_CACHE_SECONDS)
    return roots


def menu_tree():
    """Для меню: только show_in_menu, пустые подборки скрываются (count == 0)."""

    def keep(nodes):
        out = []
        for n in nodes:
            if not n.show_in_menu or n.count == 0:
                continue
            copy = Node.__new__(Node)
            for s in Node.__slots__:
                setattr(copy, s, getattr(n, s))
            copy.children = keep(n.children)
            out.append(copy)
        return out

    return keep(build_tree())


def find_node(path):
    def walk(nodes):
        for n in nodes:
            if n.full_path == path:
                return n
            if path.startswith(n.full_path + "/"):
                found = walk(n.children)
                if found:
                    return found
        return None

    return walk(build_tree())

@register.filter
def ru_plural(n, forms):
    one, few, many = forms.split(",")
    n = abs(int(n or 0))
    if n % 10 == 1 and n % 100 != 11:
        return one
    if 2 <= n % 10 <= 4 and not 12 <= n % 100 <= 14:
        return few
    return many

(function () {
  var drops = document.querySelectorAll('[data-nav-drop]');
  if (!drops.length) return;

  var desktop = window.matchMedia('(min-width: 1024px) and (hover: hover)');

  function isDesktop() {
    return desktop.matches;
  }

  for (var d = 0; d < drops.length; d++) init(drops[d]);

  function init(drop) {
    var btn = drop.querySelector('[data-nav-drop-btn]');
    var menu = drop.querySelector('[data-nav-drop-menu]');
    var items = drop.querySelectorAll('[data-tnav-item]');
    var closeTimer = null;
    var hoverTimer = null;

    function setActiveItem(item) {
      for (var i = 0; i < items.length; i++) {
        var on = items[i] === item;
        items[i].classList.toggle('is-hover', on);
        var t = items[i].querySelector('.tnav__toggle');
        if (t) t.setAttribute('aria-expanded', String(on && items[i].classList.contains('has-children')));
      }
    }

    function firstActive() {
      var cur = drop.querySelector('.tnav__item1.is-current.has-children') || drop.querySelector('.tnav__item1.has-children');
      return cur;
    }

    function open() {
      clearTimeout(closeTimer);
      if (drop.classList.contains('is-open')) return;
      closeOthers(drop);
      drop.classList.add('is-open');
      btn.setAttribute('aria-expanded', 'true');
      if (isDesktop() && !drop.querySelector('.tnav__item1.is-hover')) setActiveItem(firstActive());
    }

    function close() {
      drop.classList.remove('is-open');
      btn.setAttribute('aria-expanded', 'false');
      if (!isDesktop()) setActiveItem(null);
    }

    drop._close = close;

    btn.addEventListener('click', function (e) {
      if (isDesktop()) return;
      e.preventDefault();
      if (drop.classList.contains('is-open')) close();
      else open();
    });

    drop.addEventListener('mouseenter', function () {
      if (isDesktop()) open();
    });
    drop.addEventListener('mouseleave', function () {
      if (!isDesktop()) return;
      clearTimeout(closeTimer);
      closeTimer = setTimeout(close, 180);
    });

    for (var i = 0; i < items.length; i++) {
      (function (item) {
        item.addEventListener('mouseenter', function () {
          if (!isDesktop()) return;
          clearTimeout(hoverTimer);
          if (!item.classList.contains('has-children')) return;
          hoverTimer = setTimeout(function () { setActiveItem(item); }, 90);
        });
        var toggle = item.querySelector('.tnav__toggle');
        if (toggle) {
          toggle.addEventListener('click', function (e) {
            e.preventDefault();
            var opened = item.classList.contains('is-hover');
            setActiveItem(opened ? null : item);
          });
        }
        var sub2 = item.querySelectorAll('.tnav__item2.has-children > .tnav__link2');
        for (var k = 0; k < sub2.length; k++) {
          sub2[k].addEventListener('focus', function () {
            if (isDesktop()) setActiveItem(item);
          });
        }
      })(items[i]);
    }

    btn.addEventListener('keydown', function (e) {
      if (e.key === 'ArrowDown' || ((e.key === 'Enter' || e.key === ' ') && !drop.classList.contains('is-open') && !isDesktop())) {
        e.preventDefault();
        open();
        var first = menu.querySelector('.tnav__link1');
        if (first) first.focus();
      }
    });

    menu.addEventListener('focusin', function (e) {
      var item = e.target.closest('[data-tnav-item]');
      if (item && isDesktop() && item.classList.contains('has-children')) setActiveItem(item);
      open();
    });

    menu.addEventListener('keydown', function (e) {
      var links = Array.prototype.slice.call(menu.querySelectorAll('.tnav__link1'));
      var idx = links.indexOf(document.activeElement);
      if (e.key === 'Escape') {
        e.preventDefault();
        close();
        btn.focus();
      } else if (idx > -1 && e.key === 'ArrowDown') {
        e.preventDefault();
        links[(idx + 1) % links.length].focus();
      } else if (idx > -1 && e.key === 'ArrowUp') {
        e.preventDefault();
        links[(idx - 1 + links.length) % links.length].focus();
      } else if (idx > -1 && e.key === 'ArrowRight') {
        var panel = links[idx].parentNode.querySelector('.tnav__panel a');
        if (panel) {
          e.preventDefault();
          setActiveItem(links[idx].parentNode);
          panel.focus();
        }
      } else if (e.key === 'ArrowLeft' && idx === -1) {
        var it = document.activeElement.closest('[data-tnav-item]');
        if (it) {
          e.preventDefault();
          it.querySelector('.tnav__link1').focus();
        }
      }
    });

    drop.addEventListener('focusout', function (e) {
      if (!drop.contains(e.relatedTarget)) close();
    });
  }

  function closeOthers(except) {
    for (var i = 0; i < drops.length; i++) if (drops[i] !== except && drops[i]._close) drops[i]._close();
  }

  document.addEventListener('click', function (e) {
    for (var i = 0; i < drops.length; i++) {
      if (!drops[i].contains(e.target) && drops[i]._close) drops[i]._close();
    }
  });
  document.addEventListener('keydown', function (e) {
    if (e.key === 'Escape') closeOthers(null);
  });
})();

(function () {
  function ready(fn) { if (document.readyState !== 'loading') fn(); else document.addEventListener('DOMContentLoaded', fn); }
  ready(function () {
    var cfg = document.getElementById('pdb-reorder');
    var table = document.getElementById('result_list');
    if (!cfg || !table) return;
    var tbody = table.tBodies[0];

    var toastEl;
    function toast(text, isError) {
      if (!toastEl) { toastEl = document.createElement('div'); toastEl.className = 'pdb-toast'; document.body.appendChild(toastEl); }
      toastEl.textContent = text;
      toastEl.classList.toggle('is-error', !!isError);
      toastEl.classList.add('is-visible');
      clearTimeout(toastEl._t);
      toastEl._t = setTimeout(function () { toastEl.classList.remove('is-visible'); }, 2200);
    }
    function info(tr) {
      var h = tr.querySelector('.pdb-drag');
      return h ? { id: h.dataset.id, parent: h.dataset.parent, level: +h.dataset.level } : null;
    }
    function rows() { return Array.prototype.slice.call(tbody.rows); }
    function block(tr) {
      var lvl = info(tr).level, out = [tr], r = tr.nextElementSibling;
      while (r && info(r) && info(r).level > lvl) { out.push(r); r = r.nextElementSibling; }
      return out;
    }
    function siblings(tr) {
      var i = info(tr);
      return rows().filter(function (r) { var x = info(r); return x && x.parent === i.parent && x.level === i.level; });
    }
    function save(tr) {
      var i = info(tr);
      var ids = siblings(tr).map(function (r) { return +info(r).id; });
      fetch(cfg.dataset.url, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', 'X-CSRFToken': cfg.dataset.csrf },
        body: JSON.stringify({ parent: i.parent ? +i.parent : null, ids: ids }),
        credentials: 'same-origin'
      }).then(function (r) { return r.json().then(function (d) { if (!r.ok) throw new Error(d.error || 'Ошибка'); }); })
        .then(function () { toast('Порядок сохранён'); })
        .catch(function (e) { toast(e.message + ' — обновите страницу', true); });
    }
    function moveBlock(tr, target, before) {
      var mine = block(tr);
      if (before) mine.forEach(function (r) { tbody.insertBefore(r, target); });
      else {
        var t = block(target), ref = t[t.length - 1].nextElementSibling;
        mine.forEach(function (r) { tbody.insertBefore(r, ref); });
      }
      rows().forEach(function (r, k) { r.classList.remove('row1', 'row2'); r.classList.add(k % 2 ? 'row2' : 'row1'); });
      save(tr);
    }

    table.addEventListener('click', function (e) {
      var b = e.target.closest('.pdb-move');
      if (!b) return;
      e.preventDefault();
      var tr = b.closest('tr'), sib = siblings(tr), k = sib.indexOf(tr), dir = +b.dataset.dir, target = sib[k + dir];
      if (target) moveBlock(tr, target, dir < 0);
    });

    var drag = null;
    rows().forEach(function (r) { if (info(r)) r.setAttribute('draggable', 'true'); });
    tbody.addEventListener('dragstart', function (e) {
      drag = e.target.closest('tr');
      if (!drag || !info(drag)) { drag = null; return; }
      drag.classList.add('pdb-dragging');
      e.dataTransfer.effectAllowed = 'move';
      try { e.dataTransfer.setData('text/plain', info(drag).id); } catch (err) {}
    });
    tbody.addEventListener('dragover', function (e) {
      var over = e.target.closest('tr');
      if (!drag || !over || over === drag || siblings(drag).indexOf(over) === -1) return;
      e.preventDefault();
      rows().forEach(function (r) { r.classList.remove('pdb-drop-before', 'pdb-drop-after'); });
      var rect = over.getBoundingClientRect();
      over.classList.add(e.clientY < rect.top + rect.height / 2 ? 'pdb-drop-before' : 'pdb-drop-after');
    });
    tbody.addEventListener('drop', function (e) {
      var over = e.target.closest('tr');
      if (!drag || !over || siblings(drag).indexOf(over) === -1) return;
      e.preventDefault();
      moveBlock(drag, over, over.classList.contains('pdb-drop-before'));
    });
    tbody.addEventListener('dragend', function () {
      rows().forEach(function (r) { r.classList.remove('pdb-dragging', 'pdb-drop-before', 'pdb-drop-after'); });
      drag = null;
    });
  });
})();

  document.querySelectorAll('[data-tag-tree]').forEach(function (tree) {
  /* Карточка курса: дерево подборок */
  {
    var selected = tree.querySelector('[data-tt-selected]');
    var checks = function () { return Array.prototype.slice.call(tree.querySelectorAll('[data-tt-check]')); };
    function pathOf(input) {
      var names = [];
      var li = input.closest('[data-tt-item]');
      while (li) {
        var n = li.querySelector(':scope > .tt-row .tt-name');
        names.unshift(n.getAttribute('data-short') || n.textContent);
        li = li.parentNode.closest('[data-tt-item]');
      }
      return names.join(' › ');
    }
    function refresh() {
      checks().forEach(function (c) { c.indeterminate = false; });
      checks().forEach(function (c) {
        if (!c.checked) return;
        var li = c.closest('[data-tt-item]').parentNode.closest('[data-tt-item]');
        while (li) {
          var pc = li.querySelector(':scope > .tt-row [data-tt-check]');
          if (!pc.checked) pc.indeterminate = true;
          li = li.parentNode.closest('[data-tt-item]');
        }
      });
      var on = checks().filter(function (c) { return c.checked; });
      selected.innerHTML = on.length ? on.map(function (c) {
        return '<span class="tt-chip">' + pathOf(c) + '<button type="button" aria-label="Убрать" data-tt-remove="' + c.value + '">×</button></span>';
      }).join('') : '<span class="tt-empty">Подборки не выбраны — курс не попадёт ни в одну подборку</span>';

      var tg = e.target.closest('[data-tt-toggle]');

        var li = tg.closest('[data-tt-item]');
