# edukursy — подборки курсов (теги с иерархией до 3 уровней)

Пункт меню «Подборки курсов» рядом с «Курсы»: выпадающее меню до 3 уровней, страницы подборок
со списком курсов, полноценная админка тегов и выбор подборок в карточке курса.

Промпт для Cline — в PROMPT.md. Ниже — описание функционала.

---

## 1. Как это работает для посетителя

**Меню.** Пункт «Подборки курсов» после «Курсы».
- Компьютер (от 1024 px): при наведении открывается мега-меню. Слева — подборки 1-го уровня с иконками,
  справа — 2-й уровень заголовками колонок и 3-й уровень списком под ними. У каждой подборки — число курсов.
  Сверху справа «Все курсы с трудоустройством 111 →», внизу слева «Все подборки курсов →».
- Планшет (768–1023 px): по клику — выпадающая панель с аккордеоном.
- Телефон: внутри бургер-меню, аккордеон: тап по стрелке раскрывает 2-й и 3-й уровни, тап по названию — переход.
- Клавиатура: Tab/↑↓/→/←/Esc. Без JavaScript пункт ведёт на /podborki/.
- В меню не попадают скрытые подборки, подборки с «Не показывать в меню» и подборки без курсов.

**Подборки могут быть на любом уровне:** «Бесплатные» — только 1-й уровень (сразу ссылка с числом),
«Для начинающих» — 1-й и 2-й, «С трудоустройством» — все три.

**Страница подборки** `/podborki/<путь>/`, например `/podborki/s-trudoustrojstvom/srazu/v-it/`:
- хлебные крошки по всей цепочке, H1, описание;
- если есть вложенные подборки — чипы «Все 49 · В IT 26 · Не в IT 15» для уточнения;
- если это последний уровень — чип «← Все: Трудоустройство сразу» и соседние подборки;
- **все курсы этой подборки И всех вложенных**, без дублей: курс, отмеченный в «Сразу › В IT»,
  виден и в «Сразу», и в «С трудоустройством»;
- сортировка (популярные, дешёвые, дорогие, новые), пагинация по 24, кнопка «Сравнить» на карточках;
- пустая подборка — «В подборке пока нет курсов» + ссылка в каталог;
- скрытая подборка или подборка со скрытым родителем — 404.

**Страница всех подборок** `/podborki/` — карточки 1-го уровня, внутри 2-й и 3-й уровни с числами.

## 2. Модель данных

`CourseTag` (подборка) + поле `Course.tags = ManyToManyField(CourseTag, related_name="courses")`.

| Поле | Назначение |
|---|---|
| name | Полное название, H1 страницы: «Курсы с трудоустройством сразу» |
| menu_name | Короткое для меню: «Трудоустройство сразу» (пусто → name) |
| slug | Часть адреса, уникален внутри родителя (у разных родителей могут быть одинаковые: «v-it») |
| parent | Родитель (пусто — 1-й уровень). `on_delete=PROTECT` |
| description | Текст под H1 |
| icon | Иконка в меню (только 1-й уровень) |
| is_active | Скрыть подборку целиком (404, нет в меню), привязки к курсам сохраняются |
| show_in_menu | Убрать из меню, но оставить страницу (SEO-подборки) |
| order | Порядок внутри родителя (меняется перетаскиванием) |
| seo_title, seo_description | Необязательные SEO-поля |
| level, full_path | Считаются автоматически: 0/1/2 и «s-trudoustrojstvom/srazu/v-it» |

**Правила, которые проверяет модель:**
- не глубже 3 уровней — в том числе при переносе ветки к другому родителю (проверяется высота ветки);
- нельзя сделать родителем саму подборку или её вложенную (нет циклов);
- slug уникален у одного родителя;
- при смене slug или родителя пути всех вложенных пересчитываются;
- **удалить нельзя, если к подборке привязан хоть один курс или есть вложенные подборки** —
  проверка в `delete()`, в сигнале `pre_delete` (защищает и `QuerySet.delete()`, и shell) и `PROTECT` на parent.

Без сторонних библиотек (django-mptt/treebeard не нужны): при 3 уровнях дерево строится одним запросом.

## 3. Админка

### Список подборок
- Деревом: отступы по уровню, бейдж «ур. 1/2/3», под названием — «в меню: …» и адрес.
- Колонки: **Курсов** (привязано напрямую, ссылка на список курсов), **Всего** (с вложенными — столько увидит посетитель),
  **Активна** и **В меню** — галочки прямо в списке, **Порядок** (↑↓), **Действия**.
- Действия в строке: ✎ изменить · ＋ добавить вложенную (неактивно на 3-м уровне) · 🗑 удалить или 🔒 с подсказкой причины.
- **Сортировка:** перетаскивание строки за ⋮⋮ или стрелки ↑↓ — только среди «соседей» одного родителя,
  ветка переезжает целиком, порядок сохраняется сразу (AJAX), сообщение «Порядок сохранён».
- Поиск по названию/slug/пути, фильтры: уровень, активна, в меню, с курсами / без курсов.
- Массовые действия: «Удалить выбранные (только без курсов и вложенных)» — занятые пропускаются с сообщением,
  «Сделать активными», «Скрыть», «Показывать в меню», «Убрать из меню».
  Стандартное «Удалить выбранные» Django отключено.

### Форма подборки
- Поля: название, название в меню, slug (пусто — сгенерируется), родитель, описание, иконка, активна, в меню, порядок, SEO.
- В списке «Родитель» — только 1-й и 2-й уровень, с отступами, без самой подборки и её вложенных.
- «Адрес на сайте» — ссылка на страницу. «Курсы в подборке» — сколько напрямую и с вложенными + ссылка на список курсов.
- Ссылка «＋ добавить вложенную» открывает форму с уже выбранным родителем.
- Понятные ошибки: «Нельзя вложить глубже 3 уровней…», «Подборка с адресом … уже есть у этого родителя», «Нельзя выбрать родителем вложенную подборку».

### Удаление
- Можно: обычное подтверждение Django + чек-лист «курсов нет ✓, вложенных нет ✓, адрес начнёт отдавать 404».
- Нельзя: своя страница «Удалить нельзя» — какие вложенные (ссылки), сколько курсов (первые 5 и «ещё N», ссылка на список)
  и что сделать: снять с курсов действием «Убрать из подборки…» или просто скрыть подборку.

### Карточка курса — поле «Подборки»
- Виджет-дерево с чекбоксами вместо стандартного списка: все 3 уровня, число курсов у каждой, скрытые — серым с меткой.
- Сверху — выбранные подборки чипами с полным путём «С трудоустройством › Трудоустройство сразу › В IT» и крестиком.
- Поиск по дереву с подсветкой, «Развернуть все / Свернуть».
- Родители выбранной подборки показаны «частично» (полоска в чекбоксе). В базу пишется только отмеченное:
  отмечать родителей не нужно — курс и так появится на их страницах.
- Можно выбрать подборки любого уровня, в том числе несколько.

### Список курсов
- Колонка «Подборки» (чипы), фильтр «Подборка» деревом (выбор родителя показывает курсы и вложенных) + «Без подборок».
- Массовые действия «Добавить в подборку…» и «Убрать из подборки…» с выбором подборки рядом.

---

## 4. Производительность
- Меню и счётчики: 2 SQL-запроса на всё дерево, кэш 10 минут; кэш сбрасывается при любом изменении подборки или привязок из админки.
- Страница подборки: 5 запросов независимо от глубины.
- Список подборок в админке: ~12 запросов на всё дерево; карточка курса: ~13.
